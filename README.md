# 温故

自己用的背卡片复习网站, 照着 Quizlet 的功能做, **所有功能都不用开会员, 不限次数**。名字出自「温故而知新」。

打开就能用: **<https://aizhang453-hash.github.io/wengu/>** (电脑、手机都行, 不用注册)

## 现在能用什么 (v0.2)

- **建卡片集**: 一面写词, 一面写解释; 在最后一张的解释里按 Tab 自动加一张新的; 一键把所有卡片的词和解释对调
- **从 Quizlet 搬过来**: 在 Quizlet 上打开卡片集, 点「…」→「导出」→「复制文字」, 粘贴进来就行。
  词和解释之间认 Tab / 逗号 / 自定义, 卡片之间认换行 / 分号 / 自定义 (跟 Quizlet 导出时的选项一样), 粘贴时自动猜, 下面先给你看认出来几张。
  Excel、Word 里一列词一列解释的表格复制过来也行
- **单词卡**: 点一下 (或按空格) 翻面
  - 开着「记录会不会」: 每张标「还不会 / 会了」(手机上左右滑, 电脑上按 ← →), 能撤销;
    一轮完了告诉你会了几张, 可以接着只背还不会的, 一直背到全会
  - 关着: 就是左右翻着看
  - 能打乱顺序、先看解释、只看加了星标的
- **学习模式** (Quizlet 要会员才不限次数的那个): 每轮 7 张, 没学过的先出选择题 / 判断题, 认得了再让你自己打字, 答对就算掌握;
  答错的这一轮后面再问一次。一轮完了看看掌握了几张, 一直学到全部掌握。进度存着, 下次接着学
  - **智能判分**: 大小写、标点不算错; 括号里的可以不写; 有几个意思的写出一个就行; 打错一两个字母、少了重音符号也算对 (提醒你一下)。
    判错了可以点「我答对了」
  - 能选题型 (选择、判断、打字)、用词还是用解释回答 (或者都有)、只学星标
- **朗读**: 每张卡片都能念出来 (用浏览器自带的声音, 不用联网)。语言可以选, 也可以「自动」按字猜 (英语、中文、日语、韩语、俄语……)
- **星标**: 难记的加星标, 单词卡里可以只看这些
- **复制成文字**: 卡片集变回 Tab 和换行隔开的文字, 能直接粘回 Quizlet
- **备份**: 卡片都存在你的浏览器里, 不上传。换电脑、换浏览器或者清浏览器数据之前, 在首页点「导出备份」存一个文件, 到那边再「导入备份」
- 夜间模式跟着系统走

## 打算怎么做

Quizlet 有的功能都做上, 全部免费。一块一块做, 每做完一块都能用:

1. ✅ 建卡片集、从 Quizlet 导入、单词卡、朗读、星标、备份
2. ✅ 学习模式、智能判分
3. **测试模式**: 自动出一套卷子 (判断、选择、配对、打字), 交卷后打分, 看错在哪, 只考错的
4. **游戏**: 配对 (把词和解释连起来, 计时, 记最好成绩)、打陨石 (Quizlet 的 Blast)
5. 卡片加图片、自己录音、文字格式 (加粗、斜体、下划线、高亮)
6. 文件夹、几个卡片集合起来学、搜索、打印、断网也能用、每天该复习的 (间隔重复)、连续打卡

做不了的: 别人公开的卡片集、课堂上的实时比赛 (Quizlet Live)、教科书答案 (Expert Solutions)。
这些要一台一直开着的服务器, 或者是别人的内容, 不是自己一个网页能做的。

## 自己在电脑上跑

不用装别的东西, 有 [Node.js](https://nodejs.org/) 就行:

```sh
npm start        # 打开 http://localhost:8000
npm test         # 跑测试
```

(直接双击 `index.html` 打不开, 浏览器不让网页从文件夹里读 JavaScript 模块, 要像上面这样开一个小服务器。)

## 文件

- `index.html`、`css/style.css`: 网页和样子
- `js/app.js`: 入口, 按网址决定显示哪一页
- `js/views/`: 每一页 (首页、卡片集、编辑、单词卡、学习)
- `js/store.js`: 卡片集怎么存
- `js/parse.js`: 把粘贴的文字拆成卡片
- `js/grade.js`: 判打字的答案对不对 (智能判分)
- `js/questions.js`: 出题 (选择、判断、打字、配对)
- `js/learn.js`: 学习模式怎么排题
- `js/speech.js`: 朗读
- `tests/`: 测试
