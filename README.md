# 温故的新闻

这个分支是自动生成的：GitHub Actions（`.github/workflows/news.yml`）每 15 分钟用 `tools/news.mjs` 拿一次各家的新闻，写成 `latest.json`（所有新闻的标题、摘要）和 `a/`（能放全文的几家，一篇一个文件），温故的新闻页读这些。每次整个覆盖，只留最新的一份，不要在这里改东西。
